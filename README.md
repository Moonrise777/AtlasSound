# 🎵 Atlas Sound

## Find the Patterns That Move Us

Atlas Sound is a modern Spotify analytics dashboard built with Streamlit that explores global music trends, streaming performance, artist dominance, and the audio characteristics behind successful songs.

The platform combines Data Engineering, Business Intelligence, Exploratory Data Analysis, and Interactive Reporting into a single analytics experience.

---

## 📊 Datasets

### Spotify Global Music Dataset (2009–2025)

Contains track-level Spotify information including:

- Artists
- Track popularity
- Explicit content
- Audio features
- Albums and track metadata

Dataset:
https://www.kaggle.com/datasets/wardabilal/spotify-global-music-dataset-20092025

### Spotify Most Streamed Songs of All Time

Contains Spotify's highest-streamed songs with historical streaming performance information.

Dataset:
https://www.kaggle.com/datasets/meeratif/spotify-most-streamed-songs-of-all-time
